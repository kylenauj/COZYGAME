# Cozy Island: applying the master prompt to the current code

This document compares the current game with [`COZY_ISLAND_MASTER_PROMPT.md`](./COZY_ISLAND_MASTER_PROMPT.md)
and turns that comparison into a concrete overhaul plan. The game is `index.html` (formerly `cozy-island (23).html`):
one 7,600-line, 1.6 MB file in which 1.25 MB is embedded base64 GLB models.

The short version: **this game already has a better foundation than the generic prompt assumes.**
Its organic sculptable terrain, its merge mechanic and its living villagers are real strengths. What
it lacks is *breadth* (themes and model count), *depth of progression* (the ladder ends early, and
it can be farmed), and *placement polish* (text-only toolbar, no pop-in, no redo or recolour).
The overhaul should build on what exists rather than replace it with the prompt's tile grid.

## 2. Where the master prompt should bend to fit this game

- **Keep free placement on organic terrain.** Don't adopt the prompt's tile grid or footprints. The
  existing `radius`/`overlaps`/`resolvePlacement` system plus the optional "Snap to grid" setting
  covers it. Translate "footprint" into the existing `radius`.
- **Keep merging as the core verb.** Every new theme should ship its own merge recipes. This is
  the game's equivalent of the prompt's "set bonus", and it's more fun.
- **Keep the quiet, literary tone.** The comments, the hints ("Hums to itself. Stand near it.")
  and the hidden Reading shelf are a voice. New themes, guests and requests should be written in
  that voice, not with the prompt's "Theme combo ×3!" energy. Translate the juice into soft
  versions.
- **Palettes are the island theme system already.** The prompt's "archipelago of themed islands"
  maps directly onto *slot + palette + home theme*.

## 3. Critical issues to fix before adding content

### 3.1 Charm can be farmed ⚠️ (breaks all progression)
`placeAtHover` (L3908) adds `+10` to `state.charm`, but the eraser path in `handleClick`
(L3835 → `removeBuilding` L3792) **never subtracted it** (fixed in step 1). Placing and removing the same rock climbs
every rank in minutes, so any progression built on charm is hollow until this is fixed.

**Fix:** store the points each building earned on the building itself (`b.pts`). Subtract them on
manual removal. Don't subtract when a building is consumed by a merge, since merge bonuses are
earned. Request and secret rewards stay permanent. Charm should become *derived from what stands*
plus *permanent bonuses*. See §4.2.

### 3.2 The source pipeline isn't in the repo ⚠️ (blocks new models)
The file header says it is *"Generated by tools/build_single_file.py — edit that and the template"*,
and models come from `tools/lowpoly.py`. **Neither the tools nor the template are committed.** The
repo holds only the built output, under a filename with a browser-download suffix (`(23)`).

**Fix, in order of preference:**
1. Commit `tools/lowpoly.py`, `tools/build_single_file.py` and the template, if you still have
   them locally. Then new models are authored the same way as the existing 57.
2. Otherwise, add an in-JS **procedural model kit** (§5.3). It builds `THREE.Group`s from
   primitives using the *same named material slots* (`wall_cream`, `roof_clay`, `leaf_soft`…), so
   palettes, `TINTABLE`, `measureReach` and footings all keep working. These objects register into
   `PROTOTYPES` next to the GLB ones.

Also rename the file to `index.html`.

### 3.3 One 7.5k-line file
This works but slows every change. Restore the template/build split (or ES modules plus a tiny
concatenating build) so that catalogue data, models, systems and UI are separate files, while still
shipping a single HTML file.

## 4. Gap analysis, system by system

### 4.1 Content and themes (biggest gap)
**Have:** 57 models in 5 *implicit* themes. Toolbar groups are Village, Nature, Shore, Jungle,
Details, Ground, Tools, plus a hidden Reading shelf. The catalogue has no `theme` field.

**Existing models sorted into themes:**

| Theme | Existing models | Merge recipes already present |
|---|---|---|
| 🏡 Village | cottage, cottage_tall, well, stall, windmill, farm, flowers, bush, tree_round | cottage→manor→castle, townhouse→tower, well→fountain, stall→market hall, farm→barn, flowers→garden, oak→great oak |
| 🏖️ Castaway Shore | bungalow, palm, shelter, raft, crate, barrel, torch, fish_rack, coral, driftwood, reeds, lighthouse | torch→signal fire |
| 🌲 Wildwood | pine, rock, campfire, fern | pine→great pine, rock→boulder |
| 🌴 Jungle | jungle_tree, bamboo, fruit_bush, jungle_flower, totem | bamboo→stand, fruit bush→orchard, totem→shrine |
| 📚 Reading (hidden) | library, great_tome, book_pile, book_scatter, observatory, radio, lantern | lantern→gazebo |
| 🧰 Utility (neutral) | fence, lamp, bench, signpost | none |

**Add:**
1. `theme` and `tags` fields on every `CATALOGUE`/`MERGED` row. Make toolbar groups theme-first
   (with a "Utility" group for fences, paths and lamps).
2. **Six new theme packs** of about 12 placeables plus 2 to 3 merge results each, around 90 new
   models, which brings the total to about 150. Each pack is matched to a palette that already
   exists or is easy to add:

| New theme | Pairs with palette | Hero placeables (≈12) | Merge recipes |
|---|---|---|---|
| 🌸 Zen Garden | Blossom | sakura tree, stone lantern, torii gate, koi pond, arched bridge, raked sand, stepping stones, moss boulder, tea house, wind chime, bonsai, maple | 3 stone lanterns → pagoda; 3 sakura → great sakura; 3 stepping stones → zen garden |
| 🎃 Harvest Hollow | Autumn | pumpkin, carved pumpkin (glows), haystack, corn stalks, scarecrow, crooked tree, cauldron, friendly ghost (floats), owl post, candle cluster, harvest wagon, mushroom house | 3 pumpkins → pumpkin cottage; 3 haystacks → hay maze; 3 candles → lantern walk |
| ❄️ Winter Village | Frost / Pinewood | snowman, igloo, festive pine, present pile, sled, cocoa stand, ice pond, snowy bench, string lights post, reindeer statue, frosted cottage, snow drift | 3 snowmen → snow family; 3 igloos → ice palace; 3 festive pines → town tree |
| 🧁 Sugar Cove | new "Sugar" palette | lollipop tree, gumdrop bush, candy-cane lamp, cupcake house, gingerbread cottage, donut swing, ice-cream cart, macaron stack, chocolate fountain, cotton-candy tree, waffle bench, bakery stall | 3 cupcakes → cake castle; 3 gumdrops → candy grove |
| 🐚 Coral Reef | new "Lagoon" palette | coral (×3 kinds), giant clam, sunken chest, anchor, ship-wreck bow, jellyfish lantern (floats), sea turtle statue, buoy, shell throne, kelp | 3 corals → reef arch; 3 clams → pearl grotto |
| ✨ Starfall | night-biased "Dusk" palette | crystal cluster (glows), moon lamp, star lantern, telescope, glow mushrooms, cloud bench, comet sculpture, planet orb, moonflower bed, constellation arch | 3 crystals → crystal spire; observatory + telescope → planetarium (new 2-type recipe) |

Glowing pieces plug into the existing `GLOW_SOURCES` and lamp pool. Floaters use `FLOATERS`, and
swaying pieces use `SWAYERS`.

### 4.2 Scoring: from flat points to theme harmony
**Have:** `scoreFor` L994 gives +10, plus a one-off +50 for a Forest or Village cluster.

**Change** (keeping it legible, in the spirit of the existing comment *"simple enough to read off
the screen"*):
- `base` by size: small props 5, medium 10, buildings 20, merged forms 40.
- `harmony` multiplier from same-theme neighbours within ~6 units: 1.0 / 1.25 / 1.5 / 2.0. Reuse
  `countNear`.
- `variety`: diminishing returns for duplicates on one island (100, 90, 80%… down to a 40% floor).
- Generalise "Forest!/Village!" into **theme cluster names**: 6 or more same-theme objects close
  together pops a label such as "Zen garden", "Harvest patch" or "Reef". It pays once per cluster,
  as now.
- Store `b.pts` per building (this is the fix in §3.1). Show a hover tooltip breakdown (base ×
  harmony), so players learn *why*.
- **Island theme title:** when 60% of an island's charm comes from one theme, the island is named
  for it on the menu slot card ("Sprout Isle · a Zen garden").

### 4.3 Progression ladder
**Have:** 7 ranks (Landfall → Renown, charm 0 to 12,500). Renown opens only the observatory, and
the ladder then ends.

**Change:**
- Extend to **about 20 ranks**, every one of which opens something visible. Theme packs open
  roughly every 2 ranks. In between come new palettes, tools (redo, eyedropper, recolour), an
  extra island slot, and a new guest.
- Add an **archipelago rank** computed from charm summed across all islands. New islands unlock
  there, so the long game spans islands.
- Keep the existing good choice of showing locked chips with the rank that opens them
  (`buildToolbar` L6550).

### 4.4 Collection Book (extend Discoveries)
**Have:** `openFound` L6183 lists merged forms and secrets.

**Change:** turn it into tabbed pages, one per theme. Each page shows every object (a silhouette
until first placed), that theme's merge results, and its secrets. Completing a page (placing every
piece at least once, ever) grants a **golden variant** of the theme's hero piece and a palette
accent. This sits in shared storage (`SHARED_KEY`), like discoveries do now.

> Note: materials are shared across clones on purpose (`parseGLB` comment). Golden or recoloured
> variants need a **cached per-variant material clone** (`variantMaterial(slot, variantId)`) and
> not a per-instance clone, so that the cost stays flat.

### 4.5 Guests and requests
**Have:** 10 anonymous `REQUEST_KINDS`, one active at a time, rewarded in charm only.

**Change:**
- **One named guest per theme**, built from `makeVillager` with a signature hat or colour: a
  tea-master for Zen, a lighthouse keeper for Shore, a baker for Sugar Cove, and so on. Each
  guest arrives by boat (reuse the raft model) and has 6 to 10 requests in their theme.
- **Friendship hearts** (0 to 5). At 5, the guest moves in permanently and leaves a small daily
  gift. Some guests reward an **exclusive piece** that can't be bought.
- Allow **up to 3 open requests**, shown as a small stacked panel instead of the single
  `#request` line. Keep the existing rule that a request is never issued if it's already
  satisfied.

### 4.6 Reasons to come back (gentle, no FOMO)
- **Daily gift** on the shore: a wrapped crate (reuse `crate`) holding charm or a seasonal piece.
  A missed day costs nothing.
- **Real-date seasons:** in December, offer the Frost palette and Winter pack items. In October,
  Harvest Hollow. Items stay obtainable in later years.
- **Island growth while away:** grown trees, a new hen, a bird nesting, each with a short "While
  you were away…" note. This is in keeping with the living-world tone, and better than offline
  currency.

### 4.7 Placement UX and feel
| Missing | Suggestion | Hook |
|---|---|---|
| Toolbar is text-only | Render each prototype once at boot to a 96 px offscreen canvas; use it as the chip icon | `buildToolbar` L6550 |
| No pop-in on placement (only merges animate) | Scale 0 → 1.12 → 1 elastic over 250 ms, a leaf or sparkle puff, pitch-randomised `place` sound | `spawn` L3675, `SOUNDS.place` |
| No redo | Keep a redo stack beside `history`, cleared on new actions | `undoLast` L7282 |
| No eyedropper | Alt-click or long-press a placed object to select its type | `handleClick` L3835 |
| No per-object recolour | Swatch row of 3 to 5 variants per piece (cached variant materials) | §4.4 note |
| Fences don't connect | Auto-align a new fence's yaw to the nearest fence end within ~1.2 units | `settleYaw` |
| Too many items for tabs alone | Search box plus "recent" row in the build bar | `GROUPS` L1021 |
| No small-on-surface stacking | Later phase: `surface:true` pieces (stall, bench, picnic table) accept `small:true` props on top | `resolvePlacement` |

### 4.8 Saves
- Add `saveVersion` to slot and shared saves. Write migrations in the existing `migrateOldSave`
  style. Keep the `cozy-island:v4:*` keys readable.
- New shared fields: `collection`, `guests` (friendship, moved-in), `daily` (last gift date),
  `archipelagoCharm`. New slot fields: `homeTheme`, `b.pts`, `b.variant`.
- Add Export/Import JSON to Options (the menu already has "Save now").

## 5. Implementation roadmap (PR-sized steps)

1. **Foundation.** ✅ *Done:* renamed to `index.html`, added `SAVE_VERSION` 5 with a v4 migration,
   fixed the charm exploit (`b.pts`, `addCharm`/`takeCharm`, ranks follow the island's peak charm),
   loaded `state.done` back per island, and tagged all 57 entries with a theme (`THEMES` table).
   *Still open:* restoring or recreating the build split (§3.2, §3.3).
2. **Feel.** ✅ *Done:* chip thumbnails (drawn per palette into a small offscreen renderer), a
   pop-in and leaf/dust puff on placing, merging and removing, a knock pitched by size that steps
   up a pentatonic scale through quick runs, redo (Ctrl+Y, Ctrl+Shift+Z, touch button), and an
   eyedropper (click anything built with nothing in hand).
3. **Model kit.** Add a procedural builder registry with the shared material slots, and prove it by
   rebuilding one existing model in it to compare.
4. **Theme pack 1: Zen Garden** (pairs with the Blossom palette). This proves the whole pipeline:
   models → theme → merges → cluster label → ranks.
5. **Harmony scoring and theme titles**, plus the tooltip breakdown.
6. **Extended ranks and archipelago rank.** Slot unlocks.
7. **Collection Book** with golden variants.
8. **Guests**, friendship and multiple requests.
9. **Theme packs 2 to 6** (Harvest, Winter, Sugar, Reef, Starfall) and their palettes.
10. **Daily gift, real-date seasons, "while you were away"**, and save export/import.
